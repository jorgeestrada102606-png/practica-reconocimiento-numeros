# Práctica: Reconocimiento de Números Escritos a Mano

Este directorio contiene todo el material completo y listo para entregar de la práctica de **Reconocimiento de Números** (Dataset `load_digits` de scikit-learn).

---

## 📁 Archivos incluidos

1. **`practica_reconocimiento_numeros.ipynb`**
   - Notebook de Jupyter / Google Colab con todo el código de los 10 pasos, gráficos y las celdas de texto con las **4 preguntas respondidas** y las **conclusiones en 5 líneas**.
   - Para abrirlo en Google Colab:
     1. Entra a [colab.research.google.com](https://colab.research.google.com/)
     2. Haz clic en **Subir (Upload)**
     3. Selecciona este archivo `practica_reconocimiento_numeros.ipynb`
     4. ¡Listo! Puedes ejecutarlo celda por celda o en Menú `Entorno de ejecución > Ejecutar todas`.

2. **`practica_reconocimiento_numeros.py`**
   - Script ejecutable en Python local que corre todo el flujo y guarda los gráficos PNG generados.

3. **`respuestas_practica.md`**
   - Documento completo con todas las respuestas a las preguntas, tablas comparativas, análisis de la matriz de confusión, explicación de las matrices 8x8 creadas y las conclusiones con los datos numéricos requeridos para la rúbrica al 100%.

4. **Gráficos generados:**
   - `paso3_primeras_20_imagenes.png`: Muestra de las 20 primeras imágenes.
   - `paso4_matriz_pixeles_0.png`: Visualización con los 64 números de píxeles superpuestos.
   - `paso8_matriz_confusion_svm.png`: Matriz de confusión del modelo SVM.
   - `paso9_errores_svm.png`: Imágenes de prueba en las que SVM cometió los 4 errores.
   - `paso10_numeros_propios.png`: Comparación visual de los dos números propios diseñados.
